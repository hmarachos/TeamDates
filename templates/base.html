Справка по работе с системой
Dashboard — Главная панель

На главной странице отображается обзорная информация о днях рождения сотрудников:

  • Сегодня — список сотрудников, у которых день рождения сегодня
  • Ближайшие — сотрудники с днями рождения в ближайшие 7 дней
  • В этом месяце — все именинники текущего месяца
Сотрудники — База данных сотрудников

Раздел для управления списком сотрудников организации:

  • Просмотр — полный список с фильтрацией по компании и подразделению
  • Добавление — ручной ввод данных о сотруднике
  • Редактирование — изменение информации о сотруднике
  • Удаление — удаление сотрудника из базы
Получатели — Управление рассылкой

Настройка адресатов для email-уведомлений о днях рождения:

  • Добавление — указание имени и email получателя
  • Активация/Деактивация — включение или отключение получателя из рассылки
  • Редактирование — изменение данных получателя
Импорт — Загрузка из Excel

Массовый импорт сотрудников из файла Excel:

  • Шаблон — скачайте шаблон для заполнения
  • Формат — файлы .xlsx с колонками: Компания, ФИО, Должность, Подразделение, Дата рождения, Примечания
  • Дубликаты — при совпадении данных запись обновляется
Автоматические уведомления

Система автоматически отправляет email-уведомления:

  • Ежедневно — уведомления о днях рождения сегодня (утром)
  • Ежемесячно — список именинников следующего месяца (25-го числа)
